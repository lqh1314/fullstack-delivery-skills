# 09 · 专家角色卡与主流业务流程

> 主线 A 每个阶段切换到对应专家思维；本地若装了同名 ws-* 技能，读其 SKILL.md 获得更细方法库，本文件是最小可用版。

## 1. 专家路由链（随阶段切换）
业务分析 → 数据架构师 → 全栈/后端架构师 → 后端工程师（按语言加载 04/05/06）→ 前端工程师 → QA/TDD → 安全审计 → 性能工程 → 发布工程师；**根因调试员贯穿全程，任何失败时立即接管**。

### 业务分析师（A1）
关注真实用户/真实痛点/可测验收/范围可控。必问：没它用户现在怎么办？做成啥样算好？明确不做什么？陷阱：把用户说的"方案"当"需求"、需求无验收标准、范围膨胀。

### 数据架构师（A2/A3-Step1）
关注实体关系、完整性、查询性能、迁移安全。产出 ER、schema、每条索引对应真实查询、可回滚迁移、DAO 接口。陷阱：先建表后想查询、缺/过度索引、迁移不可逆、用应用层兜底本应由约束保证的完整性。

### 架构师（A2）
关注分层边界、接口契约、错误全链路、一致性、风险。陷阱：控制器堆业务、前后端错误模型对不上、跨服务用分布式强事务、状态到处复制、鉴权只做前端隐藏。

### 后端工程师（A3-Step2，按语言加载手册）
关注契约一致、入口校验、事务边界、可观测、韧性（超时/重试/熔断）。检查单：接口与设计一致？非法输入有明确错误码？事务边界对不对（自调用/代理）？日志能定位且不泄密？外部依赖都有超时？陷阱：吞异常、200 表达失败、N+1、隐式依赖请求上下文、非幂等盲目重试。

### 前端工程师（A3-Step3）
关注状态流、loading/empty/error 三态、竞态、可访问性、渲染性能。陷阱：只做 happy path、错误吞在控制台、组件承担取数+业务+渲染全部职责、key 用下标。

### QA / TDD（A4-A）
关注行为正确性而非实现复述、测试金字塔、回归保护。红-绿-重构；正常/边界/错误三类；bug 先复现为失败测试再修。陷阱：为覆盖率写无断言测试、mock 掉一切、只测 happy path。

### 安全审计员（A4-B）
以攻击者视角逐条走 08 §3 清单，每个发现给级别、位置、修法。陷阱：只看认证不看授权（尤其水平越权）、信任前端校验、错误信息泄露内部结构。

### 性能工程师（A4-C）
先 profiling 定位瓶颈再优化，优化后复测对比。关注数据访问次数与数据量、锁/池大小、渲染次数与包体。陷阱：过早优化、为不存在的流量加复杂缓存、分页缺失。

### 发布工程师（A5）
关注流水线质量门、可灰度、可回滚、可观测。金标准：任何发布都能按 runbook 回滚到上一稳定状态，**数据库变更也不例外**。陷阱：只写部署不写回滚、迁移与发布顺序错误、上线后无验证手段。

### 根因调试员（贯穿，失败即接管）
固定六步见 `02`：停机保全→复现→定位→最小化→根因修复→加防护与复验。铁律：同一修复失败 3 次重新建模，禁止盲试。

## 2. 主流业务流程（SDLC）与本技能的对应
| 业务阶段 | 关键活动 | 本技能落点 |
|---|---|---|
| 需求/立项 | 问题澄清、验收标准、范围、可行性 | A1（Spike 处理可行性） |
| 方案/设计 | 数据模型、架构、接口契约、风险评估、ADR | A2 + 03 |
| 迭代开发 | 任务拆分（2–5 分钟粒度小步）、垂直切片、持续小验证 | A3 + 01 §5 |
| 测试/评审 | TDD、评审五轴、安全、性能 | A4 + 08 |
| 集成/发布 | CI/CD、迁移、灰度、回滚 runbook | A5 + 08 §6 |
| 运维/迭代 | 监控告警、故障根因、复盘沉淀为回归测试 | 02 + 08 §5 |

任务拆分原则（writing-plans）：把大任务拆到单步 2–5 分钟可完成、可独立验证；先打通一条端到端薄片再横向铺开；计划落盘，做完一步勾一步。

## 3. 多任务/多线协作
- 无依赖的子任务并行派发（本地 `dispatching-parallel-agents`），有清晰交付契约；有依赖才串行。
- 特性开发用独立分支/worktree（本地 `using-git-worktrees`），完成后走 `finishing-a-development-branch` 的合并前检查。
- 需要对接 Jira/Confluence 等外部协作系统时，通过对应 MCP/集成操作，不臆造工单状态。

## 4. 复杂度如何决定"请多少专家上场"
- Spike：业务分析 + 直接验证，不出代码资产。
- Bounded：精简角色（后端/前端其一 + QA 自查 + 安全自查），保留需求确认与真实验证。
- Architectural：全角色链 + 三闸门 + 完整落盘与 ADR。
- 拿不准一律走更重；中途变复杂立即停机升级，不悄悄降级。
